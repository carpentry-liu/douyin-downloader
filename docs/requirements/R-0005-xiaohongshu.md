# R-0005 小红书内容读取和下载

在现有本地素材工具中支持小红书分享链接，用户提供两个作者主页作为验收样本。沿用每次下载新建时间戳/作者目录的规则，保存笔记正文、图片、视频和结构化记录。

- 支持小红书主页及单篇笔记；主页读取公开资料和本次可见笔记列表，再按可调上限处理笔记。
- 提供仅读取模式，保存正文或主页索引，不下载媒体；下载模式保存平台实际提供的内容。
- 保留抖音、旧素材离线合成和完整性校验能力。
- 不读取既有浏览器账号，不恢复其他项目已暂停的运营或采集任务。当前授权限本工具与用户指定的公开内容；登录、验证码和风险限制如实报告。
- 初始实测两个主页均返回登录或 300012 风险限制；不能将分享文案中的粉丝数当成已读取数据，不能伪造空主页成功。
