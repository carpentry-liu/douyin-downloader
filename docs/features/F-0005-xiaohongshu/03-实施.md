# F-0005 实施

2026-09-29，版本 0.4.0，不增加依赖。

- 新增 sharing、xiaohongshu、xhs_service，分别负责双平台分享文案、页面解析和内容归档。
- 短链识别到目标即交给独立匿名浏览器；只接受目标笔记 ID，主页下载逐篇核对作者；登录/风险页面明确报错。
- 保存标题、正文、标签、作者、页面显示统计、抓取时间；只持久化规范网页地址。笔记媒体与正文归入同一新目录，媒体失败也保留正文及 media_complete=false。
- 主页默认 20 篇，支持 1–200，有界滚动、去重与逐篇处理；保存摘要、CSV 索引、范围和下载结果。CSV 文本做公式前缀转义，缺失统计保持 null。
- 图文复用原素材清单和离线合成，扩展平台 ID 校验并保持旧清单兼容；视频复用 yt-dlp 与 FFmpeg 完整解码。
- GUI 增加仅读取按钮、主页上限及支持范围提示；CLI 增加 --read/--profile-limit，两个联网入口均受离线限制。
- 新增生成式媒体归档测试及可选真实 Edge/Chrome 契约测试。浏览器测试全部请求由生成页面满足，不访问真实平台。

## 已知范围

小红书仅保存当前页面可取得的静态图片、视频与封面，不提取图文配乐和实况；图文合成为每张 5 秒静音播放版。主页仅读取保存资料与列表，不逐篇读取正文。正常登录浏览器可见，不保证独立匿名浏览器可见。

两个真实测试主页均受当前网络的平台风险限制，因此功能处于需要真实可访问样本继续验收的阶段，不能宣称小红书实站下载已成功。发布时显式保留此限制。

## 回滚

保留旧版本地 EXE 和所有下载目录；新 EXE 使用独立文件名。源码可回退本次功能提交；新增小红书清单仅由支持该平台的版本处理，旧抖音清单保持兼容。
