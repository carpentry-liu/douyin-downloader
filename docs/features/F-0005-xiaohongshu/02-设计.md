# F-0005 实施前设计

## 模块与数据

新增 sharing 统一校验抖音/小红书链接，旧抖音解析器保持专用。新增 xiaohongshu 适配器处理短链、24 位十六进制 ID、公开页面状态、作者资料、笔记索引与媒体。浏览器使用单任务临时上下文；按页面自然加载读取状态和对应主页响应，不调用签名接口，不保存 Cookie。

主页仅处理发布笔记，默认最多 20 篇，可设 1–200。读取页面当前顺序（可能含置顶），去重后逐篇处理；记录本次上限、实际条数、是否还有更多、抓取时间和每篇成功/失败。不声称读取全部历史。遇到风险限制、验证码或登录页面立即停止该访问并明确报错。

笔记适配只接受目标 ID，校验作者绑定，禁止误取推荐内容。数值缺失保留 null；平台展示的粉丝数原样记录，不将“万”等缩写伪造为精确数。媒体 URL 和分享 token 仅留内存；持久化仅保存规范化网页链接和精选元数据。

## 输出与兼容

单篇：时间戳/作者目录内包含笔记信息.json、笔记正文.txt、原图或视频与完整性记录；图文可用原有合成器。主页：时间戳/作者目录内保存主页信息.json、笔记列表.csv、主页摘要.txt；下载的每篇笔记再放独立时间戳/作者子目录。仅读取不创建媒体文件。

原素材清单增加 platform=xiaohongshu 后允许 24 位十六进制 ID；旧抖音数值 ID 清单继续可用。原视频下载记录按平台生成来源地址，不能写成抖音链接。

## 界面与验证

保留深色工作台，输入接受双平台；增加“仅读取”按钮和主页篇数设置，离线模式同时禁用两个联网入口。CLI 增加 --read 和 --profile-limit。状态区区分只读取、下载成功、部分失败；本地保存的文本和列表可离线查看。

验证短链与主机限制、ID 匹配、页面受限、分页去重、正文/元数据、实际本地 HTTP 图片/视频下载、目录隔离、旧离线合成、GUI 主线程与离线边界。生成新版独立 EXE，以最终成品执行离线检查、抖音回归及两个真实小红书主页测试，保留真实成功与受限结果。界面使用真实截图验证；不发布私人原始响应或用户媒体。
