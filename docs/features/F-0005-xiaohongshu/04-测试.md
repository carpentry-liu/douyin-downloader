## 人工代码审查

沿用用户已选择的 OCR Python 规则，由开发代理人工检查本次差异及完整的新平台模块；没有调用独立 LLM 服务，不能称为独立模型自动审查通过。

- 修正页面跳转时执行上下文失效导致过早失败；等待有上限，目标不匹配不使用旧页面内容。
- 加强空状态、缺失统计、null 标签/互动信息与无效媒体 URL 的处理；缺失值不转成零。
- 笔记只接受当前 ID，主页下载核对作者，避免推荐内容误收；索引说明本次范围，不宣称全量。

- 精选持久化元数据，访问 token 与 CDN 签名只留内存；CSV 转义公式前缀；测试检查所有文本输出没有测试签名。
- 浏览器初始化失败时确保释放 Playwright；离线入口与 GUI 同时拒绝新读取/下载；原抖音清单和目录规则继续验证。
