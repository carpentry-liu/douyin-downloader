# F-0005 调研

2026-09-29。

| 方案 | 观察与取舍 |
|---|---|
| 整合 XHS-Downloader | 上游支持笔记媒体、正文和 livePhoto，主页链接提取由用户脚本承担；GPL-3.0，整合会改变本项目依赖和许可边界。本次不复制其代码、不引入其服务。 |
| 复用已安装 yt-dlp 下载器，加独立公开页面适配器 | 上游已有单视频适配；主页和图文仍需适配。继续使用现有 Playwright 浏览器与媒体校验组件，不增加依赖；采用。 |

主来源：[XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader)、[yt-dlp 小红书提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/xiaohongshu.py)。字段结构另参考公开客户端的 [主页解析修复](https://github.com/jackwener/xiaohongshu-cli/pull/44/files)，自行实现数据适配。

两个用户短链能够识别为不同作者主页，但 HTTP 跳转登录；独立 Edge 浏览器均显示“安全限制 / IP存在风险 / 300012”。不尝试签名破解、代理轮换或绕过登录。真实成功验收取决于平台允许访问，开发与生成式验证可独立进行。
