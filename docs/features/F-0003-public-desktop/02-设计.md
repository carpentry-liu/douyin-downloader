# F-0003 实施前设计

## 界面

- 1180×790 的深色原生窗口，最小 1000×710，适配桌面宽屏；不用在线字体或图片。实施时增加最小尺寸，为本地工具和主要操作保留空间。
- 左栏：产品标志、下载作品、本地工具、离线能力说明；打开保存目录位于底部保存位置条。
- 主区：页面标题及功能说明、步骤编号的输入区域、独立保存位置条、主操作按钮。
- 右区：任务状态、原始素材/完整播放版说明、可滚动执行记录。空态、处理中、完成、部分失败有明确文字与颜色。
- 输入支持完整分享文案，提供读取剪贴板按钮；只在用户点击时读取。Ctrl+Enter 开始下载。
- 工作线程仅产生事件，Tk 主线程修改组件。执行中锁定影响任务的操作控件，结束后恢复。
- `--offline` GUI 明确禁用新下载；本地处理仍可用。目录含空格/中文可用。

## 工程与公开

- 新增主题/视图模块，保留业务模块调用契约；媒体处理不进入 UI 层。
- 公开源码包含 src、tests、scripts、requirements、README、LICENSE、第三方说明、设计/贡献文档和新的无私人路径截图。
- 历史本机验收记录和旧截图保留本地，公开快照使用新的干净历史；源码中不得硬编码用户媒体和账号路径。
- 发布仓库前准备可检查的 Git 提交、测试证据和代码审查记录，确认公开身份和没有仓库冲突，再创建 public 仓库并推送。不强推已有远端。
- GitHub CI 在 Windows 运行生成夹具的自动测试，不下载私人示例视频，不默认发布整合二进制。

## 验证与回滚

运行全量测试、离线 UI/EXE 验收和实际窗口截图；审查完整公开源码及本次差异，修复后复验。保留旧成品备份及 Git 原分支，可本地回滚。用户下载目录不改动。
