# F-0003 实施

对应 R-0003，版本 0.3.0。

## 最终实现

继续使用 Tk 和现有下载服务，增加 desktop_view 视图模块，形成深色侧栏、下载/本地工具两页、独立保存位置和任务记录区。离线模式贯穿入口和控制器；后台任务经事件队列回到主线程更新状态。现有视频、图文、实况和原声处理接口保持兼容。

增加 MIT 许可证、贡献说明、架构文档、真实窗口截图和 Windows CI；验收脚本改为动态生成素材并验证最终 EXE，测试不依赖个人下载目录。针对离线 GUI、线程恢复和损坏素材清单增加回归覆盖。

## 审查与公开内容

使用 OCR CLI 预览和规则进行人工审查，已修复确认的问题；独立 LLM 配置不可用，用户选择继续人工规则审查。真实图文联网复验未通过，保留为公开记录中的限制，不掩盖失败。

公开仓库目标为用户确认的 `carpentry-liu/douyin-downloader`。公开分支从白名单源码创建干净历史，包含全部自研代码、测试、构建脚本和本次公开文档；个人下载、会话、旧验收记录和旧 Git 历史留在本地。整合 EXE 为本地成品，公开仓库提供源码及构建方式。

## 方案调整

窗口最终为 1180×790，最小 1000×710；主操作区优先分配空间，避免高度不足时被挤掉。打开保存目录放在全局保存条旁。原始下载目录未移动或清理，旧 EXE 已本地备份。

实际验证命令、成功和失败均见 [验证记录](../../validation.md)。
