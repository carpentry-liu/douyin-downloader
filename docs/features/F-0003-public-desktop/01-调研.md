源码采用 MIT。第三方依赖保持原许可证。首轮公开源码、测试和构建说明；既有 FFmpeg 整合 EXE 继续为本机使用版本，对外二进制分发必须单独满足对应源码和许可义务。

代码审查优先使用安装的 open-code-review CLI；初始连通性检查发现所选 siliconflow provider 未配置，继续开发并询问是否改用 OCR 规则的本地人工审查。不得将规则审查称作独立模型自动审查通过。
