# F-0004 实施

版本 0.3.1，日期 2026-09-25。

`download.create_download_folder` 统一清理昵称、读取本地时间并通过 mkdir 排他分配目录。GUI/打包入口共用 service，旧 CLI 也调用同一函数；取消两个入口的跨任务历史跳过，`--info` 仍只读取信息，不创建目录。

图文保存函数增加 `in_place=True`，先在该任务目录内部暂存并校验全部原素材，再发布媒体和清单。默认旧模式保持兼容。合成器输入和输出都使用该目录，保证原图、实况、音轨、播放版和 JSON 记录同层归档。

构建入口增加 `--name`，将本次成品命名为 DouyinLocal-v031.exe，与正在运行的旧版本并存。验收脚本从 release.json 的实际文件名复制成品，避免校验新版哈希却运行旧版文件。

回归测试使用生成式媒体和本地 HTTP 服务，覆盖视频/图文批量、重复下载、原素材模式、旧 CLI、空昵称、非法字符、同秒并发和失败后原素材保留。最初测试暴露 Windows 临时目录长短路径字符串差异，测试输出根改为 resolve 后通过，不修改用户路径或系统设置。

按既有 OCR Python 规则人工复核目录冲突、文件名边界、防覆盖、失败状态和成品选择；未引入新的模型服务或依赖。确认需同步修改的旧 CLI 历史跳过和验收文件名已处理。最终验证见 [04-测试.md](04-测试.md)。
