# F-0004 实施前设计

- 文件夹格式：`YYYY-MM-DD_HH-mm-ss_作者昵称`，使用本机当地时间，昵称清理 Windows 非法字符并限长；缺失昵称为「未知作者」。
- 对同名目录或文件使用 `_2`、`_3` 等序号；通过 mkdir 的排他创建处理并发，不复用已有路径。
- service 与旧 CLI 在解析作者后创建目录；取消跨任务历史跳过，每次单独保存。同一批分享文案重复出现的相同 URL 仍只处理一次。
- 视频 MP4 和 JSON 同目录；图文的图片、实况、原声、作品信息、完整播放版和合成记录也同目录。图文新增 in_place 参数，默认模式兼容旧调用。
- 图文先下载到该目录中的临时区并校验，再发布媒体，最后发布清单；合成失败时保留已完成的原素材。失败仍报告失败，不标记完成。
- 本地 compose 接口保持不变，可直接选择新作品目录或旧素材目录。
- build_portable 增加可选成品名称，默认名不变；验收按 release.json 指向的实际成品运行，避免误测仍在运行的旧版。

验证：生成真实视频、图片、实况与原声，通过本地 HTTP 服务验证批量、重复下载、同秒冲突、原素材与合成版共目录、旧 CLI 和非法昵称。再用最终 EXE 完成离线及真实链接验收。仅涉及保存规则，GUI 布局不变；回滚代码和成品不影响旧目录。
