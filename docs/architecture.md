# 架构与边界

```text
desktop_view（Tk 布局）
        ↓
desktop（主线程事件 + 单工作线程）
        ↓
service ── posts（匿名浏览器 / 目标作品解析）
    ├── xhs_service ── xiaohongshu（笔记 / 主页 / 访问限制）
    ├── download（原视频下载、解码、SHA-256）
    └── albums（原图、实况、原声、素材清单）

compose（本地清单 → H.264/AAC 播放版）
```

联网解析使用系统 Edge/Chrome 和独立临时上下文，不读取日常浏览器会话。仅匹配当前目标作品 ID；图文顶层 video 字段可能是音轨，实况片段来自每张图片对应的 video。

sharing 统一识别平台，保留抖音专用解析。小红书短链跳转至明确目标后停止 HTTP 跳转，由独立浏览器打开；读取页面初始状态与正常滚动引发的作者笔记响应。目标 ID 必须匹配，主页逐篇下载还校验作者 ID。分享上下文仅留内存，输出只包含无签名规范网页链接。

主页默认最多 20 篇（1–200），有界滚动与去重，记录范围及未知的 has_more，不宣称全量历史。主页输出摘要/CSV/JSON，笔记媒体在各自子目录；遇到限制保留已完成内容及失败清单。仅读取笔记保留正文，仅读取主页仅保留资料和索引。小红书图文暂为静态图片，未提取配乐/实况；无声合成每张 5 秒。

所有耗时任务在单个工作线程执行，进度进入有界队列，Tk 主线程轮询更新控件。任务进行中锁定输入、保存位置和主操作，完成后恢复。`--offline` 入口和 GUI 均禁止新下载。

原素材使用无签名 URL 的清单记录大小与 SHA-256，合成前验证。实况按索引对应图片并循环播放，各项平分完整原声时长；无声时每项 5 秒。合成版注明 locally_generated，原文件保持不变。

下载入口解析作者后，用排他 mkdir 创建 `YYYY-MM-DD_HH-mm-ss_昵称` 目录，重名自动追加序号；每条链接和每次下载均独立。视频下载器直接写该目录，图文以 in_place 模式将原素材与清单发布到该目录，合成版也写入同目录。旧 CLI 使用相同目录分配器。独立本地合成入口仍尊重指定输出路径。

单文件构建依赖 PyInstaller，运行时资源从解包目录读取，用户输出放在 EXE 旁的 downloads 或自行选择的目录。源码运行默认使用项目 downloads。构建不包含用户媒体和浏览器资料。

Windows 是桌面支持目标。网络解析受平台页面、登录要求、验证码和内容可用性影响；程序会报告失败，不能保证所有公开链接均可匿名下载。
